Política de Privacidad

Última actualización: 5 de agosto de 2026

1. Responsable del tratamiento

Isabel (en adelante, "la responsable") es la responsable del tratamiento de los datos personales recogidos a través de este sitio web.

Email de contacto: isarte2732@gmail.com

2. Datos que se recogen

Esta web recoge datos de forma automatizada a través de herramientas de análisis web. Los datos recogidos son:

  • Dirección IP (se utilza únicamente para derivar el país de origen y se descarta inmediatamente después)
  • Páginas visitadas y URL de referencia
  • Navegador y sistema operativo (a través del User-Agent)
  • Resolución de pantalla
  • País de origen (derivado de la IP)
  • Fecha y hora de la visita

No se recogen: nombres, direcciones de email, números de teléfono, ni ningún dato que permita identificar directamente a una persona. No se utilizan cookies ni tecnologías de rastreo persistentes.

3. Finalidad y base legal

Los datos se recogen con la finalidad de medición de audiencia y mejora del sitio web. La base legal es el interés legítimo del responsable (Art. 6.1.f del RGPD), que consiste en comprender cómo se utiliza el sitio para optimizar su contenido y experiencia de usuario.

No se realiza perfilado, no se toman decisiones automatizadas ni se utilizan los datos para fines publicitarios.

4. Herramientas de análisis

Esta web utiliza Umami Analytics, una herramienta de análisis web open-source y respetuosa con la privacidad.

  • No utiliza cookies
  • No rastrea usuarios entre sitios web
  • No almacena datos personales identificables
  • La IP se utiliza únicamente para derivar el país y se descarta inmediatamente
  • Los datos se envían a servidores de Umami Cloud (Estados Unidos) a través del dominio propio (primera parte)

Umami está alojado en servidores de Vercel (EE.UU.) y utiliza ClickHouse Cloud como base de datos. Puede consultar la política de privacidad de Umami en: umami.is/privacy

5. Servicios de terceros

Este sitio carga recursos desde los siguientes proveedores externos:

  • Google Fonts (Google LLC) — Fuentes web alojadas en los servidores de Google. Puede consultar su política de privacidad en: policies.google.com/privacy
  • Font Awesome (cdnjs/Cloudflare) — Iconos cargados desde la red de distribución de Cloudflare.

Cuando un usuario hace clic en los enlaces a redes sociales (TikTok, Instagram, Twitter/X), éste abandonará este sitio web. El responsable no se hace responsable de las prácticas de privacidad de dichos sitios externos.

6. Transferencias internacionales de datos

Algunos de los servicios utilizados (Umami Cloud, Google Fonts) transfieren datos fuera del Espacio Económico Europeo. Estas transferencias se realizan bajo las garantías adecuadas previstas en el RGPD, incluyendo las Cláusulas Contractuales Tipo de la Comisión Europea.

7. Conservación de los datos

Los datos de analytics se conservan durante un período de 6 meses y se eliminan automáticamente tras ese período.

8. Derechos de los usuarios

De conformidad con el RGPD, los usuarios tienen derecho a:

  • Acceso — Conocer qué datos se recogen sobre ellos
  • Rectificación — Corregir datos inexactos
  • Supresión — Solicitar la eliminación de sus datos
  • Limitación — Solicitar la limitación del tratamiento
  • Portabilidad — Recibir sus datos en formato estructurado
  • Oposición — Oponerse al tratamiento de sus datos

Para ejercer estos derechos, puede contactar a la responsable en: isarte2732@gmail.com

Si considera que el tratamiento de sus datos no se ajusta a la normativa, tiene derecho a presentar una reclamación ante la Agencia Española de Protección de Datos (AEPD): www.aepd.es

9. Cookies

Esta web no utiliza cookies. Ningún cookie se almacena en el dispositivo del usuario. Las herramientas de análisis utilizadas (Umami) funcionan sin cookies ni identificadores persistentes.

10. Menores de edad

Este sitio web no está dirigido a menores de 16 años. No se recogen deliberadamente datos de menores.

11. Cambios en esta política

Esta política de privacidad puede actualizarse para reflejar cambios en las prácticas de tratamiento de datos. Cualquier cambio será publicado en esta página con la fecha de la última actualización.
